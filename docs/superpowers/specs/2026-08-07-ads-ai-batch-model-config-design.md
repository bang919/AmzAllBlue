# 广告 AI 批量模型与推理配置设计

## 目标

将广告 AI 批量分析从 `gpt-5.5`、`high` 推理切换为 `gpt-5.6-terra`、`medium` 推理，保持每次请求最多 5 个关键词。

## 原因

当前请求通过 `cc-ai.xyz` 的 Cloudflare 代理。10 个关键词的批次拆分后，多个 5 词请求在约两分钟处收到 HTTP 524。`gpt-5.6-terra` 的 `medium` 推理可在保持分析质量的同时减少响应延迟与推理量。

## 设计

- 将全局 OpenAI 模型配置改为 `gpt-5.6-terra`。
- 将全局推理强度改为 `medium`。
- 维持批量每次最多 5 个关键词、整批 40 分钟与单次请求 5 分钟的既有配置。
- 重启服务后发送一次最小 API 验证请求；若代理不支持该模型，保留明确错误，不静默降级到旧模型。

## 验证

- 服务启动后模型配置读取为 `gpt-5.6-terra` 和 `medium`。
- 新批次仍按最多 5 个关键词分块。
- 若代理支持该模型，批量结果会写入各关键词历史；若不支持，界面显示代理返回的具体错误。
